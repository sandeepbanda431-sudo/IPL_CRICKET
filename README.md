# IPL_CRICKET
IPL Cricket Analytics Dashboard is an Excel-based data analysis project that analyzes IPL match results, team performance, and player statistics. The dashboard uses charts, KPIs, and slicer-style filters to present cricket insights in an easy-to-understand format.

## Project Objective
The objective is to analyze IPL match data and identify the best-performing teams and players. It helps compare wins, win percentages, runs, wickets, and overall team performance. The dashboard supports quick and data-driven decision-making through visual reports.

## Process
- Collected and organized IPL match, team, and player performance data in Excel.
- Cleaned and analyzed the data to calculate wins, losses, win percentage, runs, and wickets.
- Created an interactive Excel dashboard using KPI cards, charts, tables, and slicer-style filters.

## Questions (KPIs)
- Which team has the highest number of wins and win percentage?
- Which players are the top run scorers in the selected matches?
- Which bowlers have taken the highest number of wickets?
- How do teams compare based on matches played, wins, losses, and performance?
- What are the match results and performance trends across teams and venues?

- CSK, RR, and PBKS showed strong performance in the sample data, while CSK achieved a 100% win percentage.
